# Changelog

## 0.1.0 — 2026-11-02

First public beta of IPS3608 Control.

- Automatic IPS3608, DPS-150 and DPS-150P identification with model-specific limits.
- Voltage/current edits with output on, explicit output switching and confirmed readbacks.
- Live voltage/current plots, resettable V/A/W minimum, maximum and average.
- CSV recording, session energy estimates and DPS-150P microamp presentation.
- Device presets, protection thresholds, brightness and metering controls.
- Timed sequences and voltage/current sweeps, validated against live device limits.
- Local 21-tool MCP server and an agent skill sharing the desktop serial connection.
- Windows portable app and MCP executable, application icon, keyboard focus states,
  small-screen scrolling, an About dialog and per-user writable data storage.

IPS3608 hardware V1.1 was verified with firmware V1.3 and V1.9. DPS-150 and
DPS-150P have simulated-device coverage; physical verification is still needed.
